# Agile Project Documentation — Finora AI

This directory contains the official Agile project management and quality assurance documentation for the **Finora AI — Multi-Agent Financial Research & Intelligence Terminal** developed during the Infosys Internship.

## Documents Overview

### 1. `Agile_Template.xlsx`
- **Sprint Backlog & User Stories**: Sprints 1 to 4 covering US/101 through US/116.
- **Columns**: `Planned Sprint`, `Actual Sprint`, `US ID`, `User Story Description`, `MOSCOW`, `Dependency`, `Assignee` (`Udhaya Kiran`), and `Status` (`3- Completed`).
- Covers document ingestion, multi-agent architecture, vector store indexing, metric extraction, red flag scanning, cross-company comparison, and executive PDF reporting.

### 2. `Defect_Tracker.xlsx`
- **Quality Assurance & Bug Tracking**: Sprints 1 to 4 defect logs.
- **Columns**: `Sl No`, `Submitted By`, `Submitted`, `Description`, `Detected Sprint`, `Assigned To`, `Type Of Defect`, `Action Taken`, `Action Taken Date`, `Status(Open/Closed)`, `Remarks`.
- Includes root cause analysis and technical code resolutions across DocumentAgent, ExtractionAgent, ChromaDB embeddings, RedFlagAgent, and Research Copilot.

### 3. `Unit_Test_Plan.xlsx`
- **Unit Test Plan (UTP) & Test Case Specification**: 12 structured unit test cases (`UTC_001` to `UTC_012`) validating citation accuracy, numerical scaling, ratio mathematics, agent collaboration, and report generation.
- **Includes**: Test execution dashboard (100% Pass Rate), subsystem coverage matrix, defect resolution logs, and intern sign-off block.
